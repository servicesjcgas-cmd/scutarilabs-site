Straight Answers for Engineering Teams

Does scutari_core ever phone home to validate our license or collect telemetry?

No. Commercial licenses use a signed Ed25519 .lic file verified locally on boot in under 1ms. The SDK contains zero analytics, zero crash reporting beacons, and zero external server dependencies.

Do you need access to our full production repository for an Integration Sprint?

No. For regulated teams (fintech, healthcare, defense), we offer Zero-Access Delivery: we build a standalone mirror repo matching your Flutter/Android versions so your team copies the integration internally. Alternatively, we work via a restricted feature branch with Pull Request review.

Which local AI runtimes are compatible?

scutari_core is runtime-agnostic. It sits alongside LiteRT / TFLite, Gemma on-device, MediaPipe, or custom C++/ONNX delegates to govern device routing, thermal limits, and local security.
